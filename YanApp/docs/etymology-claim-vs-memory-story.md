# 词源断言与记忆联想

这是深卡和标杆词共用的最小写作规则。

## `etymologyClaim`

只用于可核对的历史词源事实。必须有权威来源、可定位到条目或页码的引用，以及能说明该来源为什么支持这条断言的简短备注。没有这些信息就不写“源自”“同根”或等价的事实语气。

## `memoryStory`

只用于帮助记忆的联想、画面或跨语言提示。用“可以这样记”“让你联想到”这类明确的提示语，不把相似发音、意义联想或教学类比写成历史事实，也不把联想到的词说成同源词。

## 分流规则

先问“这句话是在声称历史上确实如此吗？”是，就走 `etymologyClaim` 的来源门槛；否，就走 `memoryStory`，并在文案里保留联想提示。无法判断时按事实断言处理，暂不发布未经定位的词源说法。
