## 三处（数字均已独立复算，复算命令见验收）

### 1. 成员高亮对活用形永远不亮

`App.js:2426-2435`：

```js
function isFieldMemberToken(token, terms) { return terms.some(term => term === token.jp); }
```

`terms` 是成员词条的**辞书形**（`word` / `reading`），`token.jp` 是句子里的**活用形**。

```
非自身成员槽位 370，能高亮 309（83.5%）
→ 61 个槽位（16.5%）永远不亮
→ 22 条句子「一起出现」整句没有任何高亮
   n5_go_2  トルコ語を習ってるんだ。   （成员 習う，句中是 習ってる）
   n5_ato   後で取りに来ます。         （成员 取る，句中是 取り）
   n5_uta   彼が歌を歌った。           （成员 歌う，句中是 歌っ）
   n5_e     彼女は絵を見ました。       （成员 見る，句中是 見まし）
   n5_kabin 花瓶は両手で持ちなさい。   （成员 持つ，句中是 持ち）
```

commit `d11f81c` 标题是「restore inflected wordfield members」——
**内容侧刻意放了活用成员，渲染侧的匹配没跟上。**

**修法**：用 `dictionaryFormsFrom` 把 `token.jp` 还原后再比对
（和 gloss 查词同一套机制，不要新写规则）。**目标：61 → 0；做不到就逐条解释剩下的。**

### 2. `firstGloss` 在括号内切断，产出不闭合的中文

`wordFieldAlignment.js:26-29` 依次按 `;；` 和 `，、,／/` 切，**不看括号配对**：

```
全库 46 条 meaning_zh 经 firstGloss 后括号不闭合
  ～台   "……台（车辆、机器）"        → "……台（车辆"
  かかる "花费（时间、金钱）"          → "花费（时间"
  かぶる "戴（帽子等，盖在头上）"      → "戴（帽子等"
  奥さん "（您/他的）夫人"             → "（您"
  ああ   "啊（恍然/应答）"             → "啊（恍然"
```

词场句里实际出现的有 `お→（敬语`、`来→下（年`、`奥さん→（您`。

**修法**：切分时跳过括号内部（全角 `（）` 和半角 `()` 都要处理）。
如果整段第一义项本身就很长，**宁可完整显示，也不要切出半个括号**。

**注意 `wordFieldAlignment.test.mjs:136-158` 这条测试挡不住它** ——
它手挑了 10 个恰好干净的词，断言的是「不含 `，、,／/`」和「不以省略号结尾」，
上面 46 条**全部满足**。**要新增能覆盖括号的断言，并做变异验证。**

顺带一处**不要顺手改**、只写进报告：同一逻辑把
`カード` 的 `"积分卡/银行卡，卡片；贺卡"` 取成 `积分卡`，
在「店員にカードを見せます」里应该是「卡片」。
这个值被 `wordFieldAlignment.test.mjs:140` 硬编码成期望值锁死了 ——
**报告里指出来，改不改由负责人定。**

### 3. 词卡无 memo，纠错框每敲一个字重跑全库对齐

`WBDetailPage`（`App.js:2437` 起到约 2760 行）**一个 `useMemo` 都没有**（实测 0 个）。
而 `buildWordFieldAlignment` 每次调用要：`candidatesOf` 遍历 8005 条 × 2 surface
建约 16000 候选并排序；`dictionaryCandidateAt` 每个 cursor 遍历 1083 条辞书形；
`nextKnownBoundary` 对每个空洞再遍历一次全部候选。

`correctionNote` 的 `useState` 在同一个组件里（`App.js:2450`），
TextInput 在 `App.js:2729` —— **在「去纠错」的说明框里每敲一个字，整页重渲染并重跑一次全库对齐。**

**修法**：对 `fieldTokenColumns` / `buildWordFieldAlignment` 的结果做 `useMemo`，
依赖只取真正会变的（句子、gloss 词库引用）。**不要把纠错框的 state 提到别处**——
那是更大的重构。

**报告里给出**：修复前后，在同一台机器上敲 10 个字符触发的对齐调用次数
（不是耗时估算，是**调用次数**，这个可测且不依赖设备）。
