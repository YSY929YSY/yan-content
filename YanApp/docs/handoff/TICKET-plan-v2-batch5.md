## B5-1 · 修词书筛选与今日任务（🔴 最高优先）

### 现象

- N5 词书点「全部」只显示 1 个词（实际有 724 条）
- 「今日任务 10」点进去是空的，还写着「口袋还是空的，这本词书暂时没有场景词」
- 「未学」「学习中」「已掌握」同样只在那 1 个词里筛

### 根因

`App.js:2097-2099`：

```js
const defaultWords = sortByTrust(pocketWordsInBook.length ? pocketWordsInBook : sceneWordsInBook);
const searched = viewMode === 'default' ? defaultWords : wordBank;
```

默认视图**把整个数据集替换成了口袋**，于是四个状态筛选和今日任务全都在这个极小的集合上过滤。

**这是设计说错了，不是实现错了。** 上一张工单写的是「默认视图改为口袋/场景词」，
正确的意思是「**默认选中口袋这个筛选项**」——而那个 chip（`口袋 N`）本来就存在。

### 修法

- `searched` 在两种 viewMode 下都用 `wordBank`，**不再替换数据集**
- 默认 `statusFilter` 初始值改为 `'pocket'`；口袋为空时退回场景词（可以是一个 `'scene'` 筛选项，或沿用现有空态）
- `sortByTrust`（`meaningTrust` 两段式排序）仍然保留 —— **那一条测试没有否定，别顺手删掉**
- 空态文案只在**真的没有内容时**出现，不能在「今日任务 10」的情况下说「口袋还是空的」

### 验收

- 「全部」显示整本词书（N5 = 724 条量级）
- 「今日任务 N」点进去**正好是 N 个词**
- 「未学 / 学习中 / 已掌握」在整本书上筛
- 口袋 chip 仍是**默认选中**，且带正确计数
- 「浏览全库」「待复习」「搜索」全部照旧可用
- `npm test && npm run typecheck`

## B5-2 · 拼句要告诉对错（🔴）

### 现象

拼完点「提交」→ 直接翻面看答案，**不说对还是错**，而且已经自动记了一次评分。

测试者原话：

> 「这个句子拼完他不会告诉你是对的还是错的，而且我看大部分 app 的做法是……
> 你拼起来告诉你是错的还是对的，如果错了一般好像就会弹回到这个句子页面。」

### 根因

`ReviewScreen.submitProduce`：

```js
setFlipped(true);
onGrade(correct ? 'good' : 'again');
```

判定结果只用来评分，**从没显示给用户**。
比不评分更糟：用户连自己答对没有都不知道，就被记了一笔进 SRS。

### 修法

- 提交后**先显示判定**：对 → 明确的「对了」；错 → 明确的「错了」并标出正确顺序
- 错的时候**允许再拼一次**，不要直接翻面走人
- 评分时机相应后移：让用户看到结果之后才落 `onGrade`
- **不改 `srs.js` 的评分逻辑**，只改什么时候调用它
- **不接 AI 判断**，答案仍是有限集机器比对

### 验收

- 拼对：看到「对了」，然后才进档
- 拼错：看到「错了」+ 正确顺序，可以重拼；重拼对了也仍按第一次的结果计分（**不能靠重试刷成 good**）
- 单词块句子仍降级回自评（`buildProduceChoices` 的 `mode: 'self_assess'` 分支不变）
- `recall` 模式的复习行为逐像素不变
- `produceChoices.test.mjs` 全绿，并补一条「判定结果必须能被调用方读到」的测试

## B5-3 · 口袋要有一句自解释（引导）

### 为什么这条最重要

测试者**没有注意到口袋存在**，并直接问出：

> 「收入口袋是什么意思」

口袋是整个闭环的核心零件，做了两批工单。**第一个真人没看见它。**
问题不是它不好用，是它**不可见、也不自我解释**。

### 修法（只做文案与最小可见性，不做 IP、不做动画）

- 「收入口袋」按钮旁或首次点击时，给**一句话**说清它是什么。
  题面就是她的问题：收进来会怎样？—— 大意是「收着的词会进复习，之后还会问你」
- 词书里的口袋 chip 为空时，空态要说明口袋是干什么的，而不是只说「还是空的」
- 一句就够。**不要做引导流程、不要做蒙层教学、不要做角色、不要做动画**

### 明确不做

- ❌ 云朵 / 任何 IP 形象（P2，测试里「没有 IP」那句是观察，不是需求）
- ❌ 多步 onboarding
- ❌ 改口袋的数据结构或同步逻辑（那部分测试验证通过了）

### 验收

- 一个没用过的人，看到按钮附近的文字就能答出「收进去之后会发生什么」
- 文案不出现内部状态词（`candidate` / `learning` / `SRS` 之类）
- 不新增页面、不新增 Tab
