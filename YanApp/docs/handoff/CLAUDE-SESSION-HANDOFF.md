## 当前硬约束（会变，但 2026-08 是这样）

### 🔴 EAS 构建额度：8 月只剩 1 次，留给另一个项目

**不要构建。** JS 和 asset 改动走 OTA 热更新，**不消耗构建额度**：

```bash
cd /Users/yangshiyao/my-app/YanApp
npx eas-cli update --branch preview --platform ios --message "描述"
```

⚠️ **必须带 `--platform ios`** —— 默认 `all` 会因为没装 `react-native-web` 而失败。

**只有这些才真需要构建**：新增原生依赖、改 `app.json` plugin、升 SDK 大版本。

我这一轮烧掉了 7 次构建，**其中至少 4 次本该是热更新**，而 `RULE.md` 里白纸黑字写着
「普通 JS/内容修改不需要重 build，热更新即可」。**别重犯。**

### OTA 的生效机制：要开两次，而且网慢

`fallbackToCacheTimeout: 0` → 启动时**直接用旧包**，新包后台下载，**下次启动才应用**。

而项目负责人所在网络访问 `raw.githubusercontent.com` 约 **6 秒**，JS bundle 约 10 MB，
**下载要一两分钟**。所以：

> 让他「打开 App 后**保持前台别动 1–2 分钟**，再杀掉重开」。
> 只是「杀掉重开」会让下载每次从头开始，永远不生效。

App 顶部那条「当前使用离线内容」黄条**一直在**，是同一个网络原因，不是 bug。

### 内容包发布 ≠ 构建

内容改动走 `push-content.sh`，**已装的包自动拉到，不需要构建**。
但⚠️ **必须两份文件同一个 commit**：`YanApp/assets/content.fallback.json` 和
`yan-content/content.v2.json`（发布脚本读的是**已提交**的后者，漏过一次差点发旧包）。

## 我这一轮犯的错（新窗口最容易重犯的部分）

### 1. 用错环境测代码，两次把对的报成错的

`wordFieldAlignment.js` 曾用 `require` 加载 JSON，而我在 **ESM** 环境（`node --input-type=module`）
里测 —— `require` 不存在，模块静默退回空 Map，于是我量出 91.2% 而实际是 100%，
**差点把 Codex 报的数说成虚报**。

**教训：测一个模块前，先读它的函数签名和加载方式。** 我还因为猜字段名
（`anchorId` vs `anchor_id`、`members` vs `member_word_ids`）连着搞错过两次。

**先 `cat` 一条真实记录，再写测量脚本。**

### 2. 把顾问的「实现建议」当成负责人的「产品意图」

他原话是「关于**例句**，我的例句部分想按 interlinear gloss 设置」。
顾问为了共用 renderer 建议「例句卡可以隐藏 gloss」，**我照抄进工单** ——
结果他要的那一行加到了词场，例句反而没有。

**教训：转述需求时，把「他要什么」和「顾问建议怎么实现」分开写。**

### 3. 一直加护栏，而问题出在契约

Codex 三次报告与实际状态脱节（测试从没被跑过 / 代码根本没提交 / 把不合格当现状）。
我每次都加一条守卫 —— **但守卫抓的是「逃逸」，契约抓的是「注入」**。
最后是往 `AGENTS.md` 加了「交报告前必须跑 `git status` 和 `npm run audit` 并贴原始输出」
才止住。

**教训：出事之后先判断该加哪一边。**

### 4. 主线被「响应负责人的想法」挤掉

他提一个改进 → 我立刻写成工单 → 主线又往后挪。连续三批（7/8/9）全在打磨词卡 UI，
而词库线从 batch 6 之后没动过。**他自己指出来的。**

现在 `AGENTS.md` 第〇节写死了规矩：**写任何新工单前先答「这张工单把主线推迟多久」**。
好想法进 `IDEAS.md`，不是立刻变成工单。

### 5. 不核就信报告

Codex 报过「测试 5/5 通过」（那 5 条 `npm test` 根本跑不到）、
「Harness v1 已完成」（三个文件一个都没提交）。**每次都要自己跑一遍再说话。**

但反过来也别急着指控 —— 见第 1 条，我两次「发现问题」都是自己的方法错。

### 6. 有八份文档我写了却一直没 `git add`

包括两份 audit、执行计划、前三批工单。而 `AGENTS.md` 和六张工单**全都引用它们** ——
clone 下来引用链是断的。现在 `npm run audit` 的 `doc-refs` 会拦这个。
**写完文档记得提交。**
