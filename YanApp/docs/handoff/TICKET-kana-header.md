# 工单 · 五十音头部重排（删计数块，顺带修闪跳）

> 先读 `AGENTS.md` 第五节。**只改五十音这一屏的头部布局，不碰假名数据、不碰发音、不碰记忆钩子。**

## 本轮决策指标（5-4）

**切换子标签（清音 / 浊·半浊 / 拗音 / 特殊音 / 外来语）时，假名格区域顶部的位移：现状 → 0。**

不是"看起来顺了"，是**位移为 0**。给出测量方法（渲染测试里断言容器 y 坐标一致即可）。

## 根因（已定位，不用再查）

对比两屏：

```
清音     标题 → [看过 1/46 的计数块] → 平假名切换 → 子标签 → 提示卡 → 假名格
浊·半浊  标题 →                       平假名切换 → 子标签 → 提示卡 → 假名格
```

**那个计数块只有清音有。** 切走时整块消失，下面所有内容往上跳。
**不是渲染 bug，是布局不对称。**

## 要做的

### 1. 删掉计数块（整块，含那句解释）

```
看过 1 / 46 个平假名
你学过词，所以首页不拦你 —— 这里的数字只是你自己点过多少
```

**删掉的理由不是"文案不好"，是：一个需要解释自己不是门槛的数字，
说明那个数字本身长得像门槛。**（负责人原话：好的功能是点出来的，不是解释出来的。）

删掉之后闪跳自动消失 —— 一处改动解决两个问题。

**❌ 不要用进度条或 `已学 X/46` 替代它。**

- 进度条是"门槛"最强的信号形式，和删它的初衷相反
- **「已学」在声称证明不了的事**（点一下 ≠ 学会了），违反不变量 8。
  原来的「看过」是诚实的措辞

**如果将来要加回计数：要么每个子标签都有，要么都没有。** 不对称就会再跳一次。

### 2. 头部压成两行

```
第一行   清音（标题 + 副标题）        [平假名|片假名]  [对照]
第二行   [清音 | 浊·半浊 | 拗音 | 特殊音 | 外来语]     ← 一个带底轨的分段控件
```

- 五个子标签合成**一个分段控件**，不是五颗散着的 chip ——
  行高固定，本身也在防跳
- `对照` 保持现有开关行为，不改逻辑

### 3. 各子标签的提示卡高度要能对齐

清音是「汉字母语者学假名更快」，浊音是「浊点和半浊点不是装饰」，字数不同。
**如果它们高度不一致，跳动会从计数块转移到这里。**

给提示卡一个 `minHeight`，或者确认实测位移仍为 0。**以实测为准。**
