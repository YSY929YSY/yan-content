## A. Bug（必须修，按严重度排）

### A1 · 🔴 词书四个筛选和今日任务全废了

- **现象**：N5 词书「全部」只显示 1 个词；「今日任务 10」点进去是空的，还写着「口袋还是空的」
- **原因**：`App.js:2097` `defaultWords = 口袋 || 场景词`，然后 `searched = defaultWords`。
  **默认视图把整个词表替换掉了**，四个筛选和今日任务都在这个 1 个词的集合上筛
- **根因是设计说错了**：应该是「默认**选中**口袋这个筛选 chip」（chip 已存在），而不是「把数据集换掉」
- **修法**：`viewMode === 'default'` 时 `searched` 仍是 `wordBank`，只把默认 `statusFilter` 设成 `'pocket'`（口袋空时退回场景词）
- **验收**：「全部」显示整本书；「今日任务 N」点进去有 N 个词；口袋 chip 仍是默认选中项

### A2 · 🔴 拼句拼完不告诉对错

- **现象**：拼完点提交，直接翻面，**不说对还是错**
- **原因**：`ReviewScreen.submitProduce` 只做 `setFlipped(true); onGrade(correct ? 'good' : 'again')`
- **用户期待**（她的原话）：「大部分 app 的做法是……你拼起来告诉你是错的还是对的，如果错了一般好像就会弹回到这个句子页面」
- **修法**：提交后显示对/错，错的时候把正确顺序标出来，并允许再拼一次
- **注意**：现在是**自动评分**，用户连自己答对没有都不知道就被记了一笔 —— 这比不评分更糟

### A3 · 🟡 「回到场景」几乎遇不到

- **现象**：整场没看到那个按钮
- **原因**：`sourceOf(key) === 'scene'` 才显示。她遇到的是深卡（`词卡 · 餐厅点餐`），是 `card` 来源
- **修法**：深卡和地铁句也该能回到来源；或者至少让 `origin` 那一行本身可点

### A4 · 🟡 评分后不复述

- **现象**：点「不会」「一般」也直接跳过，不再讲解一遍
- **判断**：这是 SRS 的正常行为（下次到期会再问），但**第一次学的人不知道**，体感是「我说不会，它不管我」

### A5 · 🟢 内容缺口：搜「电灯泡」无结果

- 搜「灯泡」出 電球 / ランプ，搜「电灯泡」空。中文同义词没做归一

### A6 · 🟢 世界打卡：搜「卡帕多奇亚」匹配到中山市

- 已有警告 UI（「查国外地点时常常匹配错」），但她还是撞上了。**警告不等于解决**

## B. 理解断点（她问出口的问题 = 产品没自己讲清楚的地方）

**每一条都是一次「用户停下来困惑」，比任何满意度评分都值钱。**

| 她问的 | 说明什么 |
|---|---|
| **「收入口袋是什么意思」** | 🔴 口袋没有自解释。这是闭环的核心零件 |
| 「五十音有 563 条么？」 | 🔴 `0 / 563` 这个数字紧挨着五十音卡片，被读成「五十音有 563 个」 |
| 「我是先要学习五十音么？」 | 🟡 门槛存在但没说明为什么 |
| 「旅行速成 / 兴趣入门 / 考试基础 有什么区别？」 | 🟡 三个并排，两个「即将开放」 |
| 「轨道模式 / 漫游模式 有什么区别？现在是默认的对吗？」 | 🟡 同上，又一组「即将开放」 |
| 「会了」和「这个词不用再问我了」有什么区别？和百词斩的斩有什么区别？ | 🟡 两个按钮语义重叠 |
| 「为什么不同的词书点进来有不同数量的今日任务」 | 🟡 按书分会话是有意设计（`srs.js`），但没人讲 |
| 「今日任务为什么是空的，为什么点进来才显示」 | 🔴 一半是 A1 的 bug，一半是交互 |
| 「优先显示英语的功能我很感兴趣，但好像并没有优先显示」 | 🟡 **英日优先是 P2，根本没做** —— 但她以为有。说明某处文案许诺了它 |
| 「什么是入国卡」 | 🟡 例句超出零基础语境（カード 的例句是「これが入国カードですか」） |
| 「今日词根联动是什么意思」 | 🟡 需要定位是哪个入口 |
| 「复习时并列英文释义是什么意思」 | 🟢 在设置里，**她压根没滑到那里** |
| 「我怎么知道我到底有没有学会五十音」 | 🟡 只有「看过 N/46」，没有测验 |
| 「易混提醒和常见词汇对我的帮助是什么」 | 🟢 内容在，但没说清用途 |

## D. 最该正视的一条产品反馈

> 「好多功能啊……但是感觉**现在更像为旅游设计的**，核心句型什么的，但是已经很好了。
> 要是**地铁能更像游戏一样**就好了」

一个零基础用户在完整体验之后，把「言」读成了**旅行工具**，不是语言学习工具。
而她主动称赞的三样里有两样（分账、行程）**根本不属于学习线**。

这不必然是坏事 —— 但它和 `CLAUDE.md` 里「功利腿（背词）是地基、灵魂腿立在上面」的自我定位**对不上**。
本轮不裁决，但必须记下来：**这是第一份来自外部的定位证据。**

另一条：她**主动希望地铁更像游戏**，而地铁冒险恰恰是我们本轮冻结的模块。

## E. 结论与下一步

**先修 A1、A2 两个 bug**（都是这一轮自己造成的），其余一律不动。

**然后是引导，不是功能**：
- 口袋要有一句自解释（她的原话「收入口袋是什么意思」就是文案的题面）
- `0 / 563` 要挪开五十音，或者改写

**明确不做**：
- 不因为一个人说「地铁要像游戏」就去做地铁（那是 P1 冻结项）
- 不因为她夸分账/行程就往那边转（n=1，且那是另一条产品线）
- 不做英日优先（P2）
- 不做手账（她压根没看到，说明它在生产包里本来就不存在）

**下一次测试的前提**：A1/A2 修完 + 口袋有自解释，**然后测同一个人**，看她这次能不能自己注意到口袋。
