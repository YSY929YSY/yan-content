## 理论支撑

### 1. Multilingual Transfer（核心）

学界正式名称。**已有语言知识能加速学习新语言。**

- 中日共源汉字 —— **全世界语言学习里，中文使用者学日语拥有独一无二的天然优势**
- **英语跳板** —— 日语有大量英语借词；英语与西语同源 → 三语同时记
- **语言联动** —— 学了日语再学西语，共有知识能迁移

**⚠️ 这一条最容易被读窄。** 仓库里的 `kanji_anchor`（563 条）是这个原理的
**一个实例**，不是原理本身。原理是：

> **你已经会的东西，是学新东西最好的锚。**

而它是**按语言对**成立的，不是按语言：

| 语言对 | 锚 |
|---|---|
| 中文 → 日语 | 汉字 |
| 中文 → 韩语 | 韩语约六成是汉字词 |
| 英语 → 法语/西语 | 大量拉丁同源词 |
| 英语 → 德语 | 日耳曼同源（house/Haus、water/Wasser） |

**绝大多数语言 App 把「母语是什么」当噪声，一套教法套给所有人。
言的前提是母语是信号 —— 而且是最强的那个。**

### 2. 情绪记忆锚（Emotional Memory Anchoring）

> 真实经历和情感封存的记忆最久。
> **「在新宿站迷路时」比「第三课词汇」记得更长。**
> 这是言所有内容都绑定真实场景的核心逻辑。

**这一条解释了 `src/features/` 里那些「不是语言功能」的模块为什么存在**：

```
world/    世界打卡    ← 真实地点 = 记忆锚
journal/  手账        ← 真实经历 = 记忆锚
travel/   分账/行程   ← 真实行程 = 记忆锚
```

**它们不是功能蔓延，是教学法本身。** 词绑在真实经历上才记得住。
所以「地铁」这个场景不是主题包装，是言最原始的那个入口。

### 3. 情境嵌入式语法

不单独讲语法课。学完一个场景后弹语法小卡片：

> 「你刚才用的『〜ますか』就是日语的疑问句结构」

### 4. 间隔重复

已实现为 `src/features/wordbank/srs.js` 的 Leitner 阶梯 + 三档评分。
**`AGENTS.md` 不变量 3：可以改「什么时候调用它」，不能改「它怎么算」。**

## 语言路线（原始规划）

日语是**第一对**，不是全部。原始路线里已经写着西班牙语，
