# Yan 五十音例词内容规范

## 一、例词卡显示结构

例词卡第一行永远显示：
- word

例词卡第二行显示：
- 如果存在 kanji：显示 kanji + "・" + zh
- 如果不存在 kanji：显示 zh

reading：
- 可存在
- 用于朗读、检索或辅助
- 不应替代 word
- 不应替代 kanji 或 zh

## 二、字段定义

每个 examples / pairExamples 条目至少应有：
- word：日文词，显示在第一行
- reading：读音，可与 word 相同
- zh：中文释义

可选：
- kanji：日文汉字、日文对应写法，或片假名外来词的来源词/补充写法

## 三、平假名 examples 规则

平假名 examples 优先使用：
- 自然日语词
- 常见词
- 初学者能理解的基础词块
- 有自然汉字写法时，补 kanji

示例：
{
  "word": "きゃく",
  "reading": "きゃく",
  "kanji": "客",
  "zh": "客人；顾客"
}

显示效果：
きゃく
客・客人；顾客

不要：
- 冷门词
- 硬凑词
- 人名、姓氏、名人名
- 只为包含某个音而牺牲自然度

## 四、片假名 pairExamples 规则

片假名 pairExamples 优先使用：
- 自然常见片假名外来词
- 物品、食物、场景词
- 常见拟声拟态词
- 常见技术/生活词

片假名可以使用 kanji 字段表示来源词或补充写法，例如：
{
  "word": "ジュース",
  "reading": "ジュース",
  "kanji": "juice",
  "zh": "果汁；饮料"
}

显示效果：
ジュース
juice・果汁；饮料

但要注意：
- 来源词应只用于自然外来词
- 不要把中文释义写进 kanji
- zh 仍然必须是中文释义

## 五、片假名禁忌

不要使用：
- 人名
- 姓氏
- 名人音译
- 冷门专名
- 过于小众的地名
- 只为凑音而硬塞的词
- 罗马音作为 word
- 英文作为 word

允许少量使用：
- 拟声拟态词，例如 ビュー、ビュン、ビョーン、ビョンビョン
- 但 zh 必须自然

## 六、拗音 yoonRows 特别规则

拗音不使用汉字字源逻辑。
source / anchor 应表示组合规则：

きゃ:
source: "き + ゃ"
anchor: "き + ゃ → きゃ"

キャ:
pairSource: "キ + ャ"
pairAnchor: "キ + ャ → キャ"

hint 说明：
- 压成一拍
- 不要拆成 ki-ya / shi-ya / chi-ya 等

默认不要添加 confuse。
易混提醒只有在真正有教学价值时再加。

## 七、质量检查标准

每次修改 content.json 后，必须检查：

1. examples / pairExamples 每个条目是否有 word / reading / zh。
2. word 是否是日文假名或片假名。
3. word 是否为空、英文、中文、罗马音、人名。
4. kanji 是否是日文汉字、日文对应写法或自然外来语来源词。
5. zh 是否是中文释义。
6. 平假名 examples 是否自然。
7. 片假名 pairExamples 是否自然。
8. 是否有冷门硬凑词。
9. 是否有大量人名音译。
10. JSON 是否可解析。

## 八、命令

每次修改 content.json 后运行：

node -e "JSON.parse(require('fs').readFileSync('/Users/yangshiyao/my-app/yan-content/content.json','utf8')); console.log('JSON OK')"

如果修改 App.js，再运行：

node --check /Users/yangshiyao/my-app/YanApp/App.js

## 九、特殊音 specialRows 规则

特殊音不是普通五十音，也不是汉字字源演变，主要是读音规则或外来语组合规则。

### 1. 促音 っ / ッ

含义：
- 小さい つ
- 本身不读完整 tsu
- 作用是让后面的辅音停顿、加倍

示例：
- きって：kitte，不是 kite
- がっこう：gakkou
- ベッド：bed
- カップ：cup

内容字段建议：
source: "小さい つ"
pairSource: "小さい ツ"
anchor: "つ を小さく → っ"
pairAnchor: "ツ を小さく → ッ"

hint 应说明：
小っ本身不单独发完整音，而是让后面的辅音停顿/促音化。

### 2. 长音 ー

含义：
- 长音符号
- 主要用于片假名
- 作用是拉长前一个元音

示例：
- コーヒー：coffee・咖啡
- ケーキ：cake・蛋糕
- タクシー：taxi・出租车

注意：
- ー 不应被解释为一个普通假名
- 不需要复杂带写
- 重点是读音规则

### 3. 小元音 ァィゥェォ

含义：
- 主要用于外来语
- 不是传统基础五十音核心
- 用于表达 fa / fi / fe / fo / ti / di 等现代外来语音

示例：
- ファイル：file・文件
- フィルム：film・胶片；薄膜
- カフェ：café・咖啡馆
- フォーク：fork・叉子

### 4. 现代外来语组合

可作为特殊音进阶项：
- ファ / フィ / フェ / フォ
- ティ / ディ
- トゥ / ドゥ
- チェ / ジェ
- ウォ

内容重点：
- 解释组合规则
- 给自然常见片假名词
- pairExamples 可以使用 kanji 字段存来源词，例如 file、coffee、check、gelato
- 不要使用人名、冷门专名硬凑

### 5. 特殊音显示原则

- 不默认显示 SourceGhost
- 因为特殊音不是汉字字源演变
- 可以保留 StrokeMini 或轻量动画，但重点是规则说明
- examples / pairExamples 必须遵守例词规范：
  - word：日文词
  - reading：读音
  - zh：中文释义
  - kanji：可选，汉字写法或外来语来源词

### 6. 特殊音新增顺序

建议顺序：
1. っ / ッ
2. ー
3. ァィゥェォ
4. ファ / フィ / フェ / フォ
5. ティ / ディ / チェ / ジェ 等现代外来语组合

## 特殊音 specialRows 内容与交互规范

### 1. specialRows 的定位

特殊音不是普通假名字形学习，而是读音规则学习。

specialRows 详情页不应复用普通假名的完整字形学习逻辑：

- 不显示写字格
- 不显示 SourceGhost
- 不显示右上角孤立发音按钮
- 不显示“单击听发音”
- 不显示“双击展开”
- 默认展开规则说明、对比区、常见词汇

特殊音卡片单击只负责切换当前特殊音，不播放孤立发音。

### 2. 平假名 / 片假名数据读取硬规则

specialRows 必须严格区分平假名模式和片假名模式。

平假名模式读取：

- compareTitle
- compareExamples
- examples
- anchor / hint / ruleSections / ruleTips

片假名模式读取：

- pairCompareTitle
- pairCompareExamples
- pairExamples
- pairAnchor / pairHint / pairRuleSections / pairRuleTips

片假名模式下：

- 如果 pairCompareExamples 不存在或为空，必须隐藏对比区
- 禁止 fallback 到 compareExamples
- 禁止把平假名对比词显示到片假名模式

平假名模式下：

- 禁止显示片假名 pairCompareExamples
- 禁止显示片假名 pairExamples

### 3. 禁止硬凑错误词

对比区的目的不是制造错误词，而是说明读音规则造成的真实差异。

禁止为了凑对比而制造不自然词，例如：

- ベド
- カプ
- チケト
- コヒ
- ケキ
- コビニ
- さぽ
- すみませ

除非这些词本身是自然存在的日语词，否则不要作为左侧对比词。

如果没有自然对比：

- 宁可不显示对比区
- 只显示规则说明 + 常见词汇
- 不要硬凑“少了某音，不自然”的假词

### 4. 对比区内容原则

对比区只放自然对比：

- 两边最好都是自然日语词
- 或至少右侧是自然日语词，左侧不是硬造词时才可用
- 对比区用于说明“加不加某个音 / 多不多一拍，意思或听感如何变化”
- 不用于堆常见词

对比区出现过的词，原则上不要再进入常见词汇区，除非该词是绝对核心高频词且重复有明确教学价值。

### 5. 常见词汇区原则

常见词汇区用于拓展自然词，不用于解释错误形式。

平假名 examples 应使用自然平假名词。

片假名 pairExamples 应使用自然片假名词，尤其是旅行、生活、外来词高频词。

禁止把平假名词复制到 pairExamples。
禁止把片假名词复制到 examples。

### 6. 促音 っ / ッ 规则

促音平假名模式可以使用自然对比：

- きて ↔ きって
- かた ↔ かった
- いた ↔ いった

促音片假名模式如果没有自然对比，不显示对比区。

促音片假名模式只显示规则说明 + 自然片假名常见词，例如：

- ベッド
- カップ
- バッグ
- チケット
- セット
- スタッフ

禁止使用：

- ベド
- カプ
- チケト
- “少了ッ，不自然”
- “少了一，听起来不完整”

### 7. 长音 ー 规则

长音有两套逻辑，必须分开讲：

#### 片假名长音

片假名里常用 ー 表示长音。

规则简单：

- ー 本身不单独发音
- 看到 ー，就把前面的音拖长一拍

自然对比示例：

- ビル ↔ ビール

不要使用：

- コヒ ↔ コーヒー
- ケキ ↔ ケーキ

#### 平假名长音

平假名里的长音没有统一符号。

应分成两层：

直觉规则：

- あ + あ → ā，例如 おばあさん
- い + い → ī，例如 おにいさん
- う + う → ū，例如 くうこう

注意规则 / 反直觉规则：

- え + い → ē，例如 せんせい
- お + う → ō，例如 こうこう / とうきょう

不要把片假名词放进平假名长音对比区。

### 8. 拨音 ん / ン 规则

拨音 ん / ン 的重点是“单独占一拍”，不是制造缺少 ん 的错误词。

不建议使用：

- すみませ ↔ すみません
- さぽ ↔ さんぽ
- コビニ ↔ コンビニ

这些左侧不是自然表达，容易显得低质。

更推荐：

1. 用自然词说明 ん 占一拍：
   - ほん
   - さんぽ
   - でんしゃ
   - すみません
   - コンビニ
   - レストラン

2. 如果需要对比，优先使用双方都自然的词，例如：
   - みな ↔ みんな

3. 如果没有自然对比，就不要显示对比区，用“拍子示意 / 规则说明 / 常见词汇”表达。

#### 拨音 ん / ン 的特殊规范

拨音 ん / ン 的教学重点是“单独占一拍”，不是“制造缺少 ん 的错误词”，也不是解释语体差异。

不要把以下内容作为拨音核心对比：

- みな ↔ みんな
- すみませ ↔ すみません
- さぽ ↔ さんぽ
- コビニ ↔ コンビニ
- レストラ ↔ レストラン

原因：

- みな / みんな 都可以表示“大家”，区别偏语体和语感，不适合作为拨音核心教学对比。
- すみませ / さぽ / コビニ / レストラ 等不是自然词，会显得像硬造错误。
- 拨音页的重点不是“少了 ん 意思不清”，而是“ん / ン 自己也占一拍，不能吞掉”。

推荐结构：

1. 规则说明

- ん 也要占一拍
- ン 也要占一拍

2. 拍子示意 rhythmExamples

平假名可用：

- ほん：ほ・ん，♩ ♩
- さんぽ：さ・ん・ぽ，♩ ♩ ♩
- でんしゃ：で・ん・しゃ，♩ ♩ ♩
- しんかんせん：し・ん・か・ん・せ・ん，♩ ♩ ♩ ♩ ♩ ♩

片假名可用：

- パン：パ・ン，♩ ♩
- コンビニ：コ・ン・ビ・ニ，♩ ♩ ♩ ♩
- レストラン：レ・ス・ト・ラ・ン，♩ ♩ ♩ ♩ ♩
- コンセント：コ・ン・セ・ン・ト，♩ ♩ ♩ ♩ ♩

3. 常见词汇

平假名 examples 用自然词：

- ほん
- でんしゃ
- さんぽ
- すみません
- べんり
- しんかんせん

片假名 pairExamples 用自然词：

- パン
- コンビニ
- レストラン
- エンジン
- マンション
- コンセント

拨音 ん / ン 如果没有自然、清晰、无歧义的对比词，就不要显示 compareExamples / pairCompareExamples。
宁可使用 rhythmExamples 拍子示意，也不要硬凑左右对比。

Codex 修改拨音页时必须自检：

- 是否删除了 みな / みんな 作为核心对比
- 是否删除了所有硬造错误词
- 是否使用 rhythmExamples 表达“占一拍”
- 是否严格区分平假名 examples 和片假名 pairExamples

### 9. 特殊音详情内局部平 / 片切换

specialRows 详情卡内部可以有一个局部“平 / 片”切换按钮。

这个按钮不是顶部全局导航，不应跳到五十音大外框。

它只用于当前特殊音详情内部切换：

- っ ↔ ッ
- ん ↔ ン
- 平假名长音规则 ↔ 片假名 ー 规则

切换后仍停留在当前 specialRows 详情卡，不滚动跳转，不改变普通假名页逻辑。

### 10. Codex 修改原则

修改 specialRows 时，每次必须自检：

- 平假名模式有没有误用 pairExamples / pairCompareExamples
- 片假名模式有没有误用 examples / compareExamples
- 有没有硬造不自然错误词
- 对比词有没有和常见词汇重复
- 是否误改了普通清音、浊音、拗音
- 是否误显示了特殊音的孤立发音按钮或写字格

修改后运行 JSON 校验和 App.js 语法检查。

## 特殊音视觉与拍子交互规范

### 1. 特殊音页面的视觉风格

特殊音页应保持「言」的暖米色审美，不要使用偏冷的蓝紫色大背景。

推荐：
- 页面背景：沿用全站暖米色
- 详情卡背景：#FDFAF6 或接近白米色
- 边框：浅暖灰 / 浅米色
- 强调色：沿用当前橙红 / 茶橙系统
- 不使用大面积冷色背景

特殊音页的目标不是“看起来像功能卡”，而是像一本精致、清楚、可触摸的语言小册。

### 2. 长音 ー 的信息层级

长音页不能把所有信息平铺成同等权重。

长音是复杂规则，应分层展示：

1. 规则说明：说明长音的本质是“多一拍”
2. 注意规则：优先展开，因为这是最容易误读的部分
3. 拍子对比：优先展开，因为它让用户真正看见“多出来的一拍”
4. 直觉规则：可以做成紧凑小卡或默认折叠
5. 旅行高频：可以折叠或轻量展示
6. 常见词汇：可以折叠或放在后面，不抢主视觉

不要因为页面长而删内容。
应通过折叠、分层、小卡片、标签、横向排列来降低记忆负担。

### 3. 长音的教学重点

长音有两套逻辑：

片假名长音：
- ー 本身不单独发音
- 看到 ー，就把前面的音拖长一拍
- 规则简单，建立信心

平假名长音：
- 平假名没有统一长音符号
- 直觉规则：あ+あ、い+い、う+う
- 注意规则：え+い、お+う
- 注意规则才是用户最容易误读的地方，应优先展示

### 4. 拍子可视化规范

拍子不是装饰，而是核心教学工具。

如果数据里有 beats：
- 必须显示拍子
- 拍子应清楚可见
- 对长音、促音、拨音这类“一拍差异”的内容尤其重要

如果数据里有 highlightBeats：
- 对应拍子应使用强调色或加粗
- 让用户一眼看到“多出来 / 被拉长 / 不能漏掉”的那一拍

长音例：
- おばさん：♩ ♩ ♩ ♩
- おばあさん：♩ ♩ ♩ ♩ ♩
- 高亮右侧多出来的「あ」那一拍

拨音例：
- ほん：ほ・ん，♩ ♩
- 高亮 ん 对应的拍子

### 5. 拍子交互规范

第一阶段不强制做真实单拍音频切片。

可先实现：
- 点击某个拍子，播放该词完整发音
- 同时短暂高亮该拍子
- 如果该拍子属于 highlightBeats，保留强调色

不要为了实现单拍音频而重构音频系统。
后续如果有真实音频资源，再考虑逐拍播放。

### 6. 注释位置规范

compareExamples 的 note 不应漂浮在整组卡片底部。

如果 note 解释的是右侧变化后的词，应放在右侧词卡内部：
- word
- roma
- zh
- beats
- note

这样用户能明确知道 note 在解释哪个词。

### 7. 外来语页导航一致性

loanwordRows 是五十音学习系统里的外来语拓展。

外来语页应保留：
- 顶部全局导航
- 五十音内部 section tabs
- 当前 section 的明确标题和副标题

外来语以片假名为主，不需要强行显示平假名 / 片假名切换。
但必须让用户知道自己仍在五十音系统内，而不是跳到另一个页面。

如果隐藏平/片切换，应增加“片假名拓展 / 外来语音”之类的轻量提示，避免用户误以为导航缺失。

### 8. Codex 执行特殊音视觉修改前自检

每次修改特殊音视觉前，必须检查：

- 是否使用了暖色系详情卡
- 是否把长音所有内容平铺成同等权重
- 是否把注意规则和拍子对比优先展示
- 是否显示了拍子高亮
- 是否错误地删除了内容
- 是否通过排版解决复杂度，而不是偷工减料
- 是否误改了清音、浊音、拗音、外来语

### 长音 ー 的感受先行规范

长音 ー 页面应优先让用户先看到“一拍之差带来的差异”，再解释规则。

推荐顺序：

1. 先感受差异：
   - おばさん ↔ おばあさん
   - ここ ↔ こうこう
   - ビル ↔ ビール

2. 再解释规则：
   - 长音的本质是把前一个元音拉长一拍
   - 片假名里常用 ー
   - 平假名里有直觉规则和注意规则

3. 注意规则优先：
   - え + い → ē
   - お + う → ō

4. 直觉规则可以折叠：
   - あ + あ → ā
   - い + い → ī
   - う + う → ū

5. 生活高频放在后面：
   - 作为拓展，不抢主视觉

不要因为感受先行而删除规则。
不要因为页面变长而删内容。
通过顺序、折叠和层级降低理解负担。

## 词汇区去重与合并规范

### 1. 词汇区功能边界

一个词在页面中应尽量只承担一个主要教学功能：

- 规则示例：用于解释规则结构
- 对比示例：用于展示一拍、一个音造成的差异
- 高频词汇：用于拓展生活 / 旅行中真实会遇到的词

不要让同一个词在规则区、对比区、常见词汇区反复出现，除非它是绝对核心高频词，并且重复有明确教学价值。

### 2. 去重优先级

如果同一个词同时出现在多个区块，按以下优先级保留：

1. 对比示例
2. 规则示例
3. 高频词汇

也就是说：

- 已经出现在对比区的词，原则上不要再进入词汇区。
- 已经出现在规则区的词，除非是旅行 / 生活绝对高频，否则不要再进入词汇区。
- 高频词汇区不要重复解释规则区已经讲过的词。

### 3. 旅行高频与常见词汇合并

不要在同一页同时设置“旅行高频”和“常见词汇”两个功能接近的区块。

二者应合并为一个区块，推荐标题：

- 生活高频

副标题可写：

- 旅行、交通、日常里会反复遇到

合并原因：

- 减少页面重复
- 降低纵向长度
- 避免用户不清楚两个词汇区的区别
- 保持信息层级清楚

### 4. 特殊音长音页的词汇原则

长音 ー 页面尤其需要去重。

平假名长音：

- おばさん / おばあさん 如果用于对比区，不再进入生活高频。
- ここ / こうこう 如果用于对比区，不再进入生活高频。
- おにいさん / くうこう / せんせい 如果用于规则区，是否进入生活高频需谨慎。
- とうきょう / おとうさん / こうえん 属于旅行生活高频，可以进入生活高频，但不要在多个区块反复出现过多。

片假名长音：

- ビル / ビール 如果用于对比区，不再进入生活高频。
- コーヒー / ケーキ / タクシー / スーパー / メール / ホテル 可作为生活高频词汇。
- 不要为了凑数量加入低频词或硬凑词。

### 5. Codex 修改前自检

修改任何词汇区前，必须检查：

- 是否有词同时出现在规则区、对比区、词汇区
- 是否可以合并“旅行高频”和“常见词汇”
- 是否存在为了凑数量而重复高频词
- 是否存在为了凑数量而加入低频词
- 是否可以通过区块合并减少页面长度，而不是删掉关键内容

## 外来语里的小假名 loanwordRows 规范

1. loanwordRows 用于教学片假名外来语组合音，例如：
   - ファ / フィ / フェ / フォ
   - ティ / ディ
   - チェ / ジェ
   - ウォ / トゥ / ドゥ
   - ヴァ / ヴィ / ヴ / ヴェ / ヴォ

2. loanwordRows 的重点不是字形来源，也不是节奏拍子，而是：
   - 组合规则
   - 片假名外来词识别
   - 旅行 / 生活高频词汇

3. loanwordRows 不显示：
   - 写字格
   - SourceGhost
   - 汉字字源
   - 普通假名的单击发音 / 双击展开提示

4. loanwordRows 可以显示：
   - 规则说明
   - 组合规则卡
   - 生活高频词汇
   - 可选轻量发音按钮，但不强制

5. 选词原则：
   - 优先旅行、餐厅、交通、酒店、购物、日常生活高频词
   - 优先自然片假名外来词
   - 不使用人名、冷门专名、硬凑词
   - 不为了凑组合而使用低频词

6. 片假名外来词可以用 kanji 字段存来源词，例如：
   - ファイル / file・文件
   - カフェ / café・咖啡馆
   - フォーク / fork・叉子

### loanwordRows 发音交互规范

外来语里的小假名是组合音学习，必须提供轻量发音反馈。

- 点击组合卡，应播放组合音。
- 点击详情页大字，应播放当前组合音。
- 点击生活词汇卡，应播放该词。
- 不使用大喇叭按钮增加页面负担。
- 优先让整张卡片可点击。
- 发音交互不得影响清音、浊音、拗音、特殊音。
- 不新增音频依赖，优先复用现有 TTS / speak 方法。

### loanwordRows 发音显示规范

loanwordRows 需要发音反馈，但不要把“点击听发音”写在卡片上。

- ファ / フィ / フェ / フォ / ティ / ディ / チェ / ジェ 等组合音可以点击播放。
- 小ァ / 小ィ / 小ェ / 小ォ 单独不是当前学习对象，不单独做发音卡。
- 组合卡整体可点击发音。
- 详情页顶部大字可点击发音。
- 生活词汇卡整体可点击播放该词。
- 不显示“点击听发音”这类文字。
- 不使用大喇叭按钮增加页面负担。
- 如需提示，只使用 accessibilityLabel，不占用视觉空间。

### loanwordRows 组合卡交互规范

loanwordRows 是外来语组合音学习，交互应接近普通假名卡，而不是 specialRows。

组合卡交互：

- 单击组合卡：播放组合音 ch.kana
- 双击组合卡：展开 / 切换详情卡
- 不显示“点击听发音”文字
- 不显示大喇叭按钮
- 可使用轻微 pressed 状态作为反馈

词汇卡交互：

- 单击词汇卡：播放 ex.word
- 词汇卡不需要双击展开
- 词汇卡不显示“点击听发音”文字

注意：

- 小ァ / 小ィ / 小ェ / 小ォ 单独不是当前学习对象，不单独做发音卡。
- ファ / フィ / フェ / フォ / ティ / ディ / チェ / ジェ 作为组合音，可以播放。
- loanwordRows 不使用 specialRows 的“单击只切换、不播放孤立发音”逻辑。

### 平假名 / 片假名切换按钮规范

详情卡右上角的平/片切换按钮应显示“点击后将切换到的目标状态”，而不是当前状态。

- 当前显示平假名时，按钮显示「片」
- 当前显示片假名时，按钮显示「平」

这样用户能直接理解：点它会切换到另一套文字。

适用：
- 清音
- 浊音 / 半浊音
- 拗音
- 特殊音

不适用：
- 外来语 loanwordRows，因为外来语以片假名组合为主，不显示平/片切换。

### 特殊音交互规范

特殊音不是普通假名，不强调孤立发音。

- 单击特殊音卡片：切换并展开该特殊音详情
- 不需要双击展开
- 不播放孤立特殊音
- 不显示写字格
- 不显示 SourceGhost
- 不显示普通假名的“单击发音 / 双击展开”提示

特殊音重点是规则理解：
- っ：促音，听见卡住的一拍
- ー：长音，前一个音多拉一拍
- ん：拨音，单独占一拍

### 五十音 section mini 解析规范

五十音各 section 应在标题/说明区域附近显示轻量交互提示，但提示必须符合真实交互。

清音 / 浊音 / 拗音：
- 文案：轻触发音 · 双击查看记忆钩子
- 原因：普通假名卡片单击发音、双击展开详情

特殊音：
- 文案：轻触展开规则
- 原因：特殊音不强调孤立发音，单击卡片直接切换并展开规则详情
- 不写“发音”
- 不写“双击”

外来语：
- 文案：轻触发音 · 双击查看组合规则
- 原因：外来语组合卡单击播放组合音、双击展开组合规则
- 不写“记忆钩子”
- 不写“点击听发音”

交互提示应作为页面级 mini hint 显示，不应混入说明卡正文。

### 拗音 yoonRows 布局规范

拗音以三联组合呈现，每行通常为：
- ゃ
- ゅ
- ょ

布局应保持三列，但三列整体要均匀占满可用宽度。

- 不应明显偏左，造成右侧大面积空白
- 不应把单个卡片拉得过宽
- 优先通过 grid container 的横向分布、gap、padding 调整
- 清拗音、浊拗音 / 半浊拗音需要有稳定分组标题
- 分组标题应清楚但不过重
- 不要影响清音、浊音、特殊音、外来语的卡片布局

### 长音对比卡布局规范

长音 ー 的对比卡不是普通左右等宽对照。

因为右侧通常承载“长音后”的词，信息量更大：
- 假名更长
- 拍子更多
- 可能带有长音说明

因此长音 compareExamples 推荐采用略偏右侧的列宽：

- 左列：约 40% - 42%
- 中间箭头：约 8%
- 右列：约 50% - 52%

目标不是制造明显不对称，而是给右侧长音说明更多呼吸空间。

该规则只适用于长音 ー 的 compareExamples / pairCompareExamples。
不要影响促音、拨音、普通假名、外来语卡片布局。

### 特殊音关键符号颜色标注规范

特殊音详情页可以在“感受差异”的词本身里，用轻微颜色标出造成读音变化的关键符号。

使用范围：
- 促音 compareExamples / pairCompareExamples 的右侧词
- 长音 compareExamples / pairCompareExamples 的右侧词
- 拨音 rhythmExamples / pairRhythmExamples 的词

标注规则：
- 促音：标小っ / 小ッ
- 长音：只在 compareExamples / pairCompareExamples 的右侧词里标关键符号
- 拨音：标 ん / ン

长音平假名标注规则：
- 标出用于拉长前一个假名元音的后续假名
- ば + あ：标 あ
- に + い：标 い
- こ + う：标 う
- せ + い：标 い
- と + う：标 う

长音片假名标注规则：
- 只标 ー

不得用于：
- 规则说明
- ruleSections / pairRuleSections
- 规则公式
- 直觉规则 / 注意规则卡
- 生活高频
- 常见词汇区
- 外来语
- 普通假名详情

视觉规则：
- 只用暖橙色或棕橙色文字
- 可轻微加粗
- 不加箭头
- 不加标签
- 不加背景
- 不加下划线
- 不标整词
- 不在普通词汇区全局标注

目的：
标注不是装饰，也不是把所有规则字都变色。
它只帮助用户在对比 / 拍子中看见“造成变化的那个符号”。
