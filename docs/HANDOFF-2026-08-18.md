## 3. 测试和护栏的四条教训

### ① 断言的阈值不能取自被测的常量

角度断言第一版写的是 `|rotation| >= JITTER.minMagnitude`——把那个常量改成 0,
断言就变成 `>= 0`,**26 条测试照样全绿**。改成字面量后同样的篡改会挂 2 条。

**每加一条关键断言就篡改一次实现,看它会不会挂。**
这一轮靠它抓到:音调字段改回旧名挂 5 条、五十音两次篡改各挂 1 条、
义项拆分我自己补的两次篡改挂 6 条和 2 条。

### ② 有些错误,常规测试在原理上就抓不到

真机上手账拖动/双指/松手**全废**,而当时 21 条测试全绿:

```
[Worklets] Tried to synchronously call a non-worklet function `clampScale`
```

测试在 JS 线程跑,`'worklet'` 在那里只是一句无害的字符串。
补了 `worklet-guard.test.ts`(读源码做静态检查)。
⚠️ **那个护栏的检测函数第一版是假的**,是里面那条「测测试工具」的自检抓到的。

### ③ subagent 会把上游的错误照单执行

词频那个 agent 按调研的配方跑,top 是 `歯(は) 153587` —— **全是助词的频率**,
真实的 `歯` 只有 173,虚高 888 倍。它自己发现并修正了,
**但如果它照做就交,排出来的东西看起来完全合理,没人会怀疑。**

**每个 subagent 的任务书里都要写:「每个数字必须真跑,拿不到就写『未能测得』,
不要估一个数填上。」** 这一轮两个 agent 的任务书都写了这条,
两份报告的数字我逐条复核,**全部对得上**(义项那个 agent 还纠正了我一个数,见第 5 节)。

### ④ ⚠️ 新增:护栏的两半分开写,合起来会留缝

`kanaProgress.ts` 特意写了「`required` 为空时绝不能算过,这时候只认用户的
显式声明」。而 `KanaScreen` 那一屏的渲染条件写的是:

```js
{kanaReady && kanaSection === 'clear' && requiredHira.length > 0 ? (
```

**恰好在 `required` 为空的时候,那个「我已经会了」按钮不渲染。**
规则层说「只认声明」,界面层把声明的入口藏了 —— 用户被锁死在
这个 commit 本来要修的那个死循环里。

两半分开看**都是对的**,只有合起来才是洞。和第 2 节第 6 条同一个形状:
**正确性分散在两个文件里时,每个文件的作者都以为另一边会兜住。**

(这条是审计 agent 找出来的,不是我自己发现的。)

## 5. 义项拆分:数据实测(2026-08-18,已双人复核)

`meaningSenses.ts` 已做,但**只有纯逻辑层,没有任何调用方**。
下面这组数字 agent 和我各跑了一遍,一致:

| | |
|---|---|
| `meaning_en` 含 `\|` | **3017** 条 |
| 其中真的是多义词 | **3016** 条 —— 少的那条是 `半`,它的 `\|` 在括号里(见下) |
| 义项数分布(括号感知) | 1 义 4989 / 2 义 3000 / 3 义 16。**最多 3 个** |
| `\|` 的形态 | 全库 3033 次,**全部严格是 `" \| "`**,零例外 |
| 脏数据 | 空义项 0 / 首尾多余分隔符 0 / 连续 `\|\|` 0 / 括号不配平 0 |
| **`meaning_zh` 含 `\|`** | **0 条**。中文用全角 `；`(2908 条) |
| 中英义项数相等 | 3017 条里只有 **2136** 条,881 条不等(791 条英文更多) |

⚠️ **唯一的分隔符歧义,全库恰好 1 条**:

```
n5_han  半  "half (e.g., にじはん | half-past two)"
```

天真的 `split('|')` 会切出「half (e.g., にじはん」和「half-past two)」,
两个都不是词。**这一条是 agent 抓到的,我自己那版探针漏了。**
同层的 `;` 也有 13 条在括号内。

### ⚠️ 这组数字决定了义项拆分能做成什么

**中文完全没有平行结构。** 一个词英文拆出 2 个义项,中文只有压成一行的一句,
而且数量对不上的有 881 条。所以:

- ❌ 做不成「中英并列、一行一义项」
- ❌ `aligned == true` **不能当配对依据**(那 2136 条里有多少是真的语义一一对应,**未能测得**)
- ✅ 能做的是别的形态:复习时只考一个义项、或在卡上标一句「这个词还有另一个意思」

**「拆出来之后给用户看什么」这个问题还没有答案。** 别把「数据拆好了」
当成「功能做完了」—— 这正是 `conceptCluster` 那条踩过的坑(有想法,没资产)。
